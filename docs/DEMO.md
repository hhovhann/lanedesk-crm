# LaneDesk demo script (~5 min)

Run with the `dev` profile so the seed data is loaded. Story: Hayk starts the morning and works the desk.

1. **Sign in** → lands on **Today**. Point out the calls/conversations progress bars.
2. **Follow-ups due**: "Pacific Rim Electronics" is due (no answer earlier). Click **Voicemail**: the row disappears, and a new follow-up is scheduled. One click.
3. **Call list**: everyone shown is inside 8–5 in *their own* time zone (clock shown next to each). Click **Talked** on a prospect.
4. Open **Lone Star Building Supply** (a follow-up with a warm lead). Type notes ("needs 3 flatbeds/wk"), choose *Follow up: in a week*, click **Talked**. Timeline updates in place.
5. Same page → **+ Quote a load**: Dallas TX → Denver CO, flatbed, 42,000 lbs, $2,650. Try 50,000 lbs first to show the weight rule.
6. **Pipeline**: click **Won ✓** on the new load. Click **Cover**, pick *Flatland Hauling* with cost $2,000 (margin appears). **Picked up → In transit → Delivered ✓**.
7. Try **Cover** without a carrier and **Lost** without a reason: both refuse.
8. **Bayou Chemical Supply** (Do Not Call): banner shown, no call form, never on Today.
9. **Stats**: calls vs target, win rate, margin and commission for the week and month.
10. **Companies → Import CSV**: upload a file, show imported vs. skipped-as-duplicate.
